> 📋 轻量桌面版客户关系管理工具，基于 Ttkbootstrap + SQLite 构建，面向销售团队、小微企业客户台账管理场景。纯本地离线运行，所有数据保存在本地 SQLite 数据库，无需部署服务、无需联网。

## ✨ 核心特性
- 🏠 **首页数据看板**：客户总数、今日/明日待回访、今日已回访统计，展示今日待回访明细，程序启动自动回访提醒。
- 📋 **客户台账管理**：客户新增、编辑、删除；多条件搜索、高级筛选（阶段、标签）；表格点击表头排序。
- 📝 **跟进日志系统**：跟进记录新增、编辑、删除；自动补全客户选择组件；支持设置下次回访提醒。
- 📊 **导入导出能力**：XLSX向导式导入，智能字段映射；支持 CSV / XLSX 多维度导出（全量导出、按跟进日期导出、按下次回访日期导出）。
- ⚙️ **外部配置驱动**：`config.json` 统一管理表格列、下拉选项、导入映射，无需修改代码即可调整界面字段。
- 💾 **本地存储**：SQLite 单文件数据库 `crm.db`，数据完全保存在本地，无云端上传。

## 📦 环境依赖
Python >= 3.10

依赖包：
```bash
pip install ttkbootstrap openpyxl
```

## 🚀 快速开始
1. 将 `main.py` 与 `config.json` 放置在**同一个目录**下
2. 执行程序
```bash
python main.py
```

> 我们不推荐直接双击打开文件，因为可能会导致程序意外崩溃。

3. 首次运行会自动生成 `crm.db` SQLite数据库文件。

> ⚠️ 重要：不要删除、移动 `config.json`，程序启动依赖该配置文件。

## 📁 项目文件说明
| 文件 | 说明 |
|---|---|
| `main.py` | 主程序源代码 |
| `config.json` | 全局配置文件：表格列定义、下拉选项、导入导出字段映射 |
| `crm.db` | SQLite数据库文件，程序运行自动生成，存放全部客户&跟进日志数据 |
| `LICENSE` | Apache‑2.0 许可证文件 |

## ⚙️ 配置自定义
修改 `config.json` 可以实现：
- 修改客户阶段、跟进方式下拉选项
- 修改表格显示列、列宽、是否可见
- 修改客户详情弹窗显示字段
- 修改CSV导入字段映射关系

> 修改配置文件后重启程序生效。

## 📋 功能清单
### 客户台账
- 新增客户，校验企业名称重复
- 双击打开客户详情弹窗，支持编辑全部客户字段，查看该客户全部历史跟进记录
- 删除客户（同步级联删除该客户所有跟进日志，不可恢复）
- 普通搜索：企业名称 / 法人 / 电话 / 跟进备注模糊检索
- 高级筛选：客户阶段、标签模糊匹配
- XLSX导入向导：预览数据、自定义字段映射，支持可选导入数据库已存在扩展字段
- 导出：全量CSV/XLSX导出

### 跟进日志
- 自动补全客户输入框，快速选择客户
- 新增、编辑、删除跟进记录
- 设置跟进日期、下次回访提醒日期
- 表格点击表头排序
- 按跟进日期、下次回访日期范围导出跟进记录 CSV / XLSX

### 首页看板
- 数据卡片统计：客户总数、今日待回访、明日待回访、今日已回访
- 今日待回访明细列表
- 程序启动 + 后台定时弹出回访提醒

## ⚠️ 使用注意事项
1. **数据备份**：定期备份 `crm.db` 文件，防止误删或磁盘损坏造成数据丢失。删除客户会连带删除全部关联跟进记录，操作不可撤销。
2. **文件路径**：运行时 `main.py`、`config.json` 需要放在同一文件夹。
3. **XLSX导入**：Excel表头支持智能别名匹配，可手动调整映射；不存在于数据库的Excel额外列不会自动创建数据库字段。
4. **平台兼容**：Windows体验最佳；Mac / Linux 下tkinter组件需要系统预装tk。Termux不支持GUI图形界面，无法运行。
